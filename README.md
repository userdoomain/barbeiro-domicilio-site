# Barbeiro a Domicílio

Site de conversão do **Barbeiro a Domicílio** em Niterói (Icaraí, Centro e Santa Rosa).

## Tecnologias

- HTML5 + CSS3 + JavaScript puro
- Sem frameworks ou dependências externas (exceto Google Fonts)
- Hospedagem: GitHub Pages

## Estrutura

```
├── index.html
├── RESEARCH.md          # Pesquisa e dados confirmados
├── ASSETS-SOURCES.md    # Fontes de imagens e assets
└── assets/
    ├── css/style.css
    ├── js/main.js
    └── favicon.svg
```

## Conversão

Site focado em conversão via WhatsApp. CTA principal: "Agendar pelo WhatsApp".
